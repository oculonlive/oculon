Start here

Four commands, in the order most people run them.

01

Install

Needs Node.js 22.13 or newer (nodejs.org). No runtime dependencies. To try it without installing, put npx in front of any command, e.g. npx oculon tour.

$npm install -g oculon
02

Take the tour

Shows what this install knows and what to try next.

$oculon tour
03

Open the web app

Overview page, console, dashboard and these docs, with the schedule and live streams running.

$oculon serve --watch 15 --live
04

Connect an agent

Add the remote MCP server to Claude Code, or run oculon mcp on stdio.

$claude mcp add --transport http oculon https://mcp.oculon.live

Verify a forecast yourself

Forecast proofs do not depend on this server. For any forecast id: /api/proof?id=<id> gives the forecast, its canonical JSON, hash and Merkle path, and /proof/<id>.ots is a standard OpenTimestamps file.

sha256(canonicalJson) == leaf               # the forecast was not edited
leaf + merklePath -> root                   # it is in the stamped batch
ots verify -d <root> <id>.ots              # the root is committed in a Bitcoin block
