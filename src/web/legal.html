Who this covers

This notice describes how the Oculon software (CLI, SDK, MCP server, this web app and the Telegram bot) handles information. Whoever runs an Oculon install is responsible for that install and for any public deployment of these pages.

What Oculon stores

  • A local SQLite database with signals, entities, links, cached API responses, watchlist items, geofences, case files and feedback votes, in ~/.oculon or the folder set by OCULON_HOME.
  • API keys you add to your .env file. They are read locally and sent only to the service each key belongs to.
  • Nothing is sent to the Oculon authors. There is no usage reporting, crash reporting or tracking.

What leaves your machine

  • Queries to public data sources. When a module runs, it calls the sources it needs (for example USGS, Cloudflare Radar, Blockscout or GeckoTerminal)(for example USGS, Cloudflare Radar, NVD or NASA) with the inputs you gave it, such as an address, a domain or a place name.such as a domain, a company or a place name. Each source handles those requests under its own policy.
  • Questions to language models. Commands such as ask, case and the daily brief send your question and the collected evidence to the LLM providers you configured keys for (Groq, Google Gemini, Mistral, OpenRouter, NVIDIA or Anthropic). Without a key, nothing is sent.
  • Telegram. If you run the bot, alerts and answers go to the chats you allow-listed, through Telegram's servers.
  • This web page. The landing page, app and docs load fonts from Google Fonts, map libraries from cdnjs and map outlines from jsDelivr, so your browser contacts those services when it opens them.

Cookies and browser storage

The pages set no cookies. The app remembers your light or dark theme in your browser's local storage, and nothing else.

Who can reach an install

oculon serve listens on 127.0.0.1 by default, so only the same machine can open it. Actions that change data accept only same-origin requests with a custom header. If you put an install behind a public domain, you decide who can reach it.

Removing data

Delete the Oculon data folder to remove everything it stored. oculon gc trims the cache without removing your watchlist or cases.

Data sources

Oculon reads public and free-tier sources run by other organisations. Their data stays subject to their own terms, rate limits and attribution rules. You are responsible for keeping your use within those terms, including for any API keys you add. Every Oculon result names the sources behind it and whether each answer was live or cached.

Not advice

Signals, scores, verdicts and forecasts are automated readings of public data. They are not financial, legal, security or investment advice. Token and deployer verdicts on Robinhood Chain and other chains are heuristics over pool and explorer data, not contract audits. A DANGER or OK verdict can be wrong.Scores are heuristics over public data, not audits or ratings, and a high or low score can be wrong.

Accuracy and availability

Sources can be late, wrong, rate-limited or offline, and free tiers can change. When a source fails, Oculon labels it and returns the rest of the result. Language-model output can be mistaken; answers cite the evidence they used so you can check it.

Acceptable use

  • Use Oculon lawfully, and respect the privacy of the people and organisations you research.
  • Do not use it to harass, stalk or target private individuals, or to evade sanctions or other legal obligations.
  • Do not overload the sources it reads. The daily budgets exist to keep usage within their free limits.

Imagery and map data

Satellite and night imagery on these pages comes from NASA GIBS (Black Marble, Blue Marble). Country outlines come from Natural Earth via world-atlas. Both are public domain.
