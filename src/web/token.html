How to check an address

The official address is posted in three places at the same time. Before you use any address, make sure it matches all three exactly, character by character.

X@oculonlive GITHUBoculonlive/oculon WEBoculon.live/thetoken

If an address is missing from any of the three, it is not Oculon. Oculon will never message you first, ask for your recovery phrase, or ask you to send funds to an address.

What Oculon is

Oculon is a free, open-source OSINT engine under the MIT licence. It checks things before you trust them: a suspicious message, a link, a phone number, a leaked password, a supplier, an IP address, a vulnerability or a news claim. Every answer lists the sources it used and whether each was live, cached or unavailable.

It runs as a CLI (npx oculon), a TypeScript SDK, an MCP server for AI agents, the web app at oculon.live and a Telegram bot.
