Oculon Embed

Give your visitors a link checker, or warn them before they follow a dangerous link off your site. One script tag, no dependencies, no cookies, and it never blocks a link when Oculon cannot be reached.

Live preview · box

Paste any link or domain. The check runs on Oculon's link checker: Safe Browsing, URLhaus, urlscan.io, domain age and look-alike signs.

Live preview · links

Links in this panel are watched. Click one: a clean destination opens as usual; a malicious or suspicious one shows a warning first.

Add it to your site

A "Check a link" box

Paste this where the box should appear. Or put <div id="oculon-check"></div> anywhere on the page and the script fills it.

<script src="https://oculon.live/embed.js" data-oculon-mode="box" async></script>

Warn before dangerous outbound links

Add this once, anywhere on the page. Links to your own site and its subdomains are never checked.

<script src="https://oculon.live/embed.js" data-oculon-mode="links" async></script>

Only the links in a comment section, with a light box

<script src="https://oculon.live/embed.js" data-oculon-mode="links" data-oculon-scope="#comments" data-oculon-warn="malicious" async></script>
<script src="https://oculon.live/embed.js" data-oculon-mode="box" data-oculon-theme="light" async></script>

Options

AttributeDefaultWhat it does
data-oculon-modeboxbox shows a link checker; links checks outbound links when they are clicked.
data-oculon-targetoculon-checkId of the element the box goes into. Without one, the box appears where the script tag is.
data-oculon-warnsuspiciousWhich results show a warning in links mode: suspicious warns on suspicious and malicious, malicious only on malicious.
data-oculon-scopewhole pageA CSS selector. Only links inside it are checked, for example #comments.
data-oculon-allownoneComma-separated hosts that are never checked, such as your partners. Your own site is always skipped.
data-oculon-max20Most checks per page view (1 to 50). After that, links go through unchecked.
data-oculon-themedarkdark or light.
data-oculon-keynoneAn Oculon API key, sent as Authorization: Bearer. Not needed today; reserved for higher limits later.
data-oculon-apiscript originThe Oculon server to ask. Leave it out for oculon.live; set it when you run your own Oculon.

How it behaves

  • Never in the way. In links mode a click waits at most a few seconds for the check. If Oculon is slow, down or rate limited, the link opens as if the script were not there.
  • Most clicks are instant. A link is checked when the visitor hovers or focuses it, so the answer is usually ready before the click. Results are kept for 30 minutes in the tab's session storage.
  • Gentle on the API. One check per link, a limit per page view, and repeated clicks reuse the first answer. The public API allows a few checks per minute per visitor.
  • Isolated. The box and the warning live in a shadow DOM, so your styles do not break them and theirs do not leak into your page.
  • What is sent. Only the link being checked goes to Oculon. No cookies, no page content, no visitor data. Modifier clicks (open in a new tab) are not stopped; they are checked in the background for next time.
  • What a result means. "No known threats" means the sources had nothing on the link at that moment. It is not a promise that a page is safe.

Free. The script is about 17 KB unminified and loads with async, so it never delays your page.
