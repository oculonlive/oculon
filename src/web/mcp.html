Remote MCP server · online

Oculon for your agent.
One URL, nothing to install.

Add this server to Claude, Cursor, VS Code or any MCP client and your agent can check scams, links, claims, recalls, travel risk, CVEs, outages and research, with the source of every fact.

{{URL}}

Streamable HTTP, stateless JSON. No account and no key. This page is what a browser sees; agents POST JSON-RPC to the same URL.

Connect

Claude Code

Run once in a terminal.

claude mcp add --transport http oculon {{URL}}

Claude (web and desktop)

Settings → Connectors → Add custom connector, then paste the URL.

Cursor
