06 · How it works
Sources in.
Evidence out.

  
Every answer travels the same four steps, so every answer can show where it came from and how fresh it is.

  

    
01
Fetch
Public APIs over plain HTTP with a local cache and a daily budget per source. When a budget is spent, the last cached answer is served and labelled.

    
02
Module
Each module parses, filters and scores what changed. Baselines come from earlier scans, so a surge is measured against its own history.

    
03
Graph
Signals, entities and links land in one local SQLite graph with their evidence and provenance, ready for connect A to B.

    
04
Surface
The same result object goes to the CLI, the SDK, the MCP server, this web app and the Telegram bot.

00 · Questions
Before you
install.

  
Short answers. The documentation has the long ones.

  

    
Does it cost anything?
No. Oculon is MIT licensed. About 20 sources work with no key, and the rest use free tiers. A daily budget per source keeps usage inside those free limits.

    
Where does my data go?
Into a local SQLite file in ~/.oculon. Nothing is sent to the authors; there is no telemetry. Queries go only to the sources a command needs. See Privacy.

    
What do I need to run it?
Node.js 22.13 or newer. npm i -g oculon, then oculon tour shows what your install can already do. To try it without installing, use npx oculon tour.

    
Can my AI agent use it?
Yes. Add https://mcp.oculon.live as a remote MCP server in Claude, Cursor or VS Code and its 71 tools are ready with nothing to install. oculon mcp runs the same server locally on stdio, and the TypeScript SDK returns the same result objects as the CLI.

    
Does Robinhood Chain need a key?
No. Heron reads pool data from GeckoTerminal and contract data from Blockscout without keys.

    
Are the verdicts audits?
No. Token and deployer verdicts are heuristics over pool and explorer data, and every verdict lists the reasons behind it so you can judge them.

    
Which sources need a key?
About 20 work with none. oculon doctor lists which optional keys are set and what each one switches on.

    
Are the scores predictions?
No. A score says how unusual something is across independent sources, and every signal lists the evidence behind it so you can judge it.
