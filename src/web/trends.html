How these numbers are made

  • Only counts. Each stored check adds one to its kind and its verdict. Messages, links, addresses, numbers and names are never read out.
  • Fixed categories. Warning signs are matched to a fixed list of the wording Oculon's checks use; anything else is ignored. Brands come from the fixed list the link check knows.
  • Small groups stay hidden. A kind, verdict, sign, brand or domain ending with fewer than 3 checks is not shown, so no single check can be picked out.

These are the checks run on this Oculon server, not a survey of all scams. JSON at /api/trends.
