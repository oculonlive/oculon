Prove It

Show that a file existed by a certain time: a contract, a design, a manuscript, a screenshot. Your browser computes the file's SHA-256 hash and only that hash is sent. It is timestamped through OpenTimestamps and anchored in a Bitcoin block, so anyone can check it later without trusting Oculon.

What this proves, and what it does not

It proves

These exact bytes existed no later than the time of the Bitcoin block named in the proof. Change a single byte and the hash no longer matches.

What it does not prove

Who made the file, who submitted it, that its contents are true, or that it was created at that moment. Only that it existed by then.

  • Pending first. The OpenTimestamps calendars collect hashes and write them into Bitcoin about once per block. A new proof is usually confirmed within a few hours; Oculon checks every half hour.
  • Keep the file and the proof. The proof only works with the exact original file. Download the .ots file once it is confirmed and keep it with the original.
  • Check it without us. Run ots verify -d <hash> proof.ots with the OpenTimestamps client, or drop the file and the proof on opentimestamps.org.
  • Labels are public. Anyone with the hash can see the label you gave it. Leave it empty for anything private.

Free and keyless: OpenTimestamps public calendars and the Blockstream block explorer. Same file twice returns the same proof. JSON at /api/prove?hash=.
