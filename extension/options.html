OCULON SHIELD

Settings

Site guard

Check the domain of each page you open. Dangerous sites get a full-page warning, sites to be careful on get a small banner, and the toolbar badge shows the verdict.

Token pills

On DexScreener, Uniswap and the Robinhood Chain explorers, show the Oculon contract check for the token on the page.

API base URL

Where checks are sent. The default is the public Oculon server. A self-hosted Oculon server works too; the browser will ask for permission to reach it.

Allowed sites

Sites you chose to continue to from a warning stay allowed until the browser closes.

Privacy: Oculon Shield sends only the domain, link, address or contract being checked to the API above. No browsing history, no analytics, no tracking. Results are cached in the browser session only.
